# منبّه أخبار التعلّم في Discord

يجمع هذا السكربت الأخبار من مصادر RSS/Atom، ويترجمها إلى العربية، وينشرها في أربع قنوات من سيرفرك على Discord:

| القناة | نوعها | المصادر | اسم الـ Secret |
|---|---|---|---|
| الذكاء الاصطناعي | منتدى (Forum) | OpenAI، Hugging Face، Google DeepMind، The Verge (قسم AI)، و**إصدارات الأدوات الجديدة**: Claude Code، Ollama، Codex CLI، Gemini CLI، Open WebUI، Transformers | `DISCORD_WEBHOOK_AI` |
| البرمجة | منتدى (Forum) | GitHub Blog، Hacker News (الأخبار التي تجاوزت 300 نقطة فقط) | `DISCORD_WEBHOOK_PROGRAMMING` |
| الأمن السيبراني | منتدى (Forum) | The Hacker News، Krebs on Security، BleepingComputer | `DISCORD_WEBHOOK_SECURITY` |
| مقالات—أبحاث—دراسات | نصية (Text) | arXiv (cs.AI وcs.CR وcs.SE)، Quanta Magazine | `DISCORD_WEBHOOK_RESEARCH` |

- **كل خبر في رسالة مستقلة:** في قنوات المنتدى يصبح كل خبر **منشورًا (Post) جديدًا** عنوانه العنوان العربي، وفي القناة النصية يصل رسالةً عادية.
- **البطاقة:** العنوان بالعربية، وملخص عربي (نحو 300 حرف)، واسم المصدر، والرابط، وصورة الخبر إن وُجدت، والعنوان الإنجليزي الأصلي بخط صغير في أسفلها.
- **إصدارات الأدوات:** مثل «🆕 Claude Code v2.1.301» مع أهم ما في ملاحظات الإصدار مترجمًا. الإصدارات التجريبية (alpha وbeta وrc وnightly وpreview) لا تُنشر.
- **أبحاث arXiv:** الأوراق الجديدة فقط (لا النسخ المحدّثة من أوراق قديمة)، مع أسماء المؤلفين.
- **حد أقصى:** 3 أخبار من كل مصدر في كل تشغيل (2 من Hacker News)، الأحدث أولًا. ما زاد على ذلك يُتجاهَل ولا يتراكم، فلا تُغرق القنوات بأخبار قديمة.
- **التوقيت:** يعمل مجانًا على خوادم GitHub Actions كل 6 ساعات: 00:08 و06:08 و12:08 و18:08 بتوقيت دمشق (UTC+3)، حتى وجهازك مطفأ.
- **الترجمة مجانية** عبر خدمة [MyMemory](https://mymemory.translated.net/). أسماء المنتجات والأرقام والأكواد تبقى كما هي.
  إذا تعذّرت الترجمة تظهر البطاقة بالإنجليزية.

المتوقع نحو 40 إلى 70 خبرًا يوميًا في القنوات الأربع معًا.

## الخطوة 1: أنشئ Webhook في كل قناة من القنوات الأربع

تحتاج صلاحية **Manage Webhooks** في السيرفر (صاحب السيرفر يملكها). كرّر ما يلي **لكل قناة من القنوات الأربع**:

1. مرّر المؤشر على اسم القناة واضغط ⚙️ (**Edit Channel**).
2. اختر **Integrations** ← **Webhooks** ← **New Webhook**.
3. سمِّه مثلًا `أخبار الذكاء الاصطناعي`، ويمكنك وضع صورة له.
4. اضغط **Save Changes**. ستحتاج زر **Copy Webhook URL** في الخطوة 4.

> 💡 الأسهل أن تنسخ رابط كل قناة وتضعه مباشرةً في الـ Secret الخاص بها (الخطوة 4) واحدًا تلو الآخر، فلا تحتاج حفظه في أي مكان.

> ⚠️ **رابط الـ Webhook سرّي** مثل كلمة المرور: من يملكه يستطيع النشر في قناتك.
> لا تلصقه في أي محادثة أو ملف أو داخل الكود. ضعه فقط في الـ Secret كما في الخطوة 4.
> إذا تسرّب، احذف الـ Webhook من Discord وأنشئ واحدًا جديدًا.

**مهم لقنوات المنتدى:** إذا كان خيار **Require people to select tags when posting** مفعّلًا في إعدادات القناة،
فسيرفض Discord منشورات الـ Webhook. أوقفه، أو ضع أرقام الوسوم (tag IDs) في `applied_tags` داخل `feeds.json` (انظر «تعديل المصادر»).

## الخطوة 2: أنشئ مستودعًا جديدًا على GitHub

1. ادخل إلى <https://github.com/new>.
2. اسم المستودع مثلًا `learning-news-notifier`.
3. اختر **Public** (عام): المستودع العام يحصل على دقائق Actions مجانية بلا حد، وروابط الـ Webhook لا تظهر فيه لأنها محفوظة كـ Secrets.
4. اضغط **Create repository**.

## الخطوة 3: ارفع الملفات

**من المتصفح:** في صفحة المستودع الجديد اضغط **uploading an existing file** (أو **Add file ← Upload files**)،
ثم اسحب **محتويات** هذا المجلد كلها، ومنها مجلد `.github`:

```
.github/workflows/notify.yml
.gitignore
README.md
feeds.json
notifier.py
tests/test_notifier.py
```

ثم اضغط **Commit changes**. تأكد بعد الرفع أن الملف `.github/workflows/notify.yml` ظاهر في المستودع.

**أو من الطرفية** (إذا كنت تستخدم git وGitHub CLI)، من داخل هذا المجلد:

```bash
git init -b main
```

```bash
git add .
```

```bash
git commit -m "Learning news notifier"
```

```bash
gh repo create learning-news-notifier --public --source . --push
```

## الخطوة 4: أضف روابط الـ Webhooks كـ Secrets

1. في صفحة مستودعك: **Settings** ← **Secrets and variables** ← **Actions**.
2. اضغط **New repository secret**.
3. في **Name** اكتب الاسم **بالضبط** من الجدول، وفي **Secret** الصق رابط Webhook القناة المقابلة، ثم **Add secret**.
4. كرّر ذلك للقنوات الأربع:

| Name | رابط Webhook قناة |
|---|---|
| `DISCORD_WEBHOOK_AI` | الذكاء الاصطناعي |
| `DISCORD_WEBHOOK_PROGRAMMING` | البرمجة |
| `DISCORD_WEBHOOK_SECURITY` | الأمن السيبراني |
| `DISCORD_WEBHOOK_RESEARCH` | مقالات—أبحاث—دراسات |

انتبه ألّا تبدّل بين الروابط، وإلا وصلت الأخبار إلى القناة الخطأ.

## الخطوة 5: أضف MYMEMORY_EMAIL (مهم)

كل خبر يحتاج ترجمة نحو 400 حرف (العنوان والملخص)، أي نحو 25000 حرف يوميًا.
تسمح MyMemory دون تسجيل بـ **5000 حرف فقط** يوميًا، وخوادم GitHub يتشارك عناوينها مستخدمون كثيرون.
إذا أضفت بريدًا إلكترونيًا ترتفع الحصة إلى **50000 حرف يوميًا**، وهذا يكفي:

1. **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**.
2. **Name:** `MYMEMORY_EMAIL`، و**Secret:** بريدك الإلكتروني.

البريد يُرسل إلى MyMemory فقط مع طلبات الترجمة، ولا يظهر في المستودع.
دونه تنفد الحصة بعد أول بضعة أخبار، فتصل بقية أخبار اليوم بالإنجليزية.

## الخطوة 6: جرّب

1. افتح تبويب **Actions** في مستودعك. إذا ظهرت رسالة تطلب تفعيل الـ workflows فاضغط زر التفعيل.
2. **تجربة دون نشر:** اختر **Learning news to Discord** ← **Run workflow**، وفعّل خانة `dry_run`، واكتب `1` في خانة `latest`، ثم **Run workflow**.
   افتح التشغيل ← `notify` ← خطوة **Post new items to Discord**: ستجد رسائل القنوات الأربع مطبوعة (بصيغة JSON) بعناوينها العربية.
   لا يُرسل شيء إلى Discord ولا يُنشأ `state.json`.
3. **تجربة النشر الفعلي في قناة واحدة:** **Run workflow** مرة أخرى دون `dry_run`، واكتب `research` في خانة `channel` و`1` في خانة `latest`.
   سيُنشر أحدث خبر من كل مصدر في قناة الأبحاث (4 رسائل). كرّر ذلك مع `security` (3 منشورات) و`programming` (منشوران) و`ai` (10 منشورات).
   أو اترك `channel` فارغًا لتجربة القنوات الأربع معًا (نحو 19 رسالة).

بعد ذلك يعمل وحده كل 6 ساعات ولا ينشر إلا الجديد.
أول تشغيل عادي (`latest` = `0`) يسجّل ما في المصادر الآن على أنه «منشور» دون أن ينشر شيئًا، ثم تبدأ الأخبار الجديدة بالوصول.

## تعديل المصادر (feeds.json)

كل القنوات والمصادر في الملف `feeds.json`، ويمكنك تعديله من GitHub مباشرةً (افتح الملف ← ✏️).

**إضافة أداة من GitHub** إلى «ما الجديد» في قناة الذكاء الاصطناعي، أضف سطرًا مثل هذا داخل `feeds` (وانتبه للفاصلة بين الأسطر):

```json
{"name": "LM Studio", "url": "https://github.com/OWNER/REPO/releases.atom", "kind": "release"}
```

**إضافات المصدر** (كلها اختيارية ما عدا `name` و`url`):

| الإعداد | المعنى |
|---|---|
| `name` | اسم المصدر كما يظهر في البطاقة |
| `url` | رابط RSS أو Atom |
| `limit` | أقصى عدد أخبار من هذا المصدر في كل تشغيل (الافتراضي 3؛ و`0` يوقفه مؤقتًا) |
| `kind` | `"release"` لإصدارات GitHub: عنوان «🆕 الأداة + رقم الإصدار» وملخص ملاحظات الإصدار |
| `prereleases` | `true` لنشر الإصدارات التجريبية أيضًا |
| `skip_title` | تعبير نمطي (regex): لا يُنشر الخبر إذا طابق عنوانه |
| `skip_text` | تعبير نمطي: لا يُنشر الخبر إذا طابق نصه (يُستخدم لاستبعاد تحديثات arXiv) |
| `page_image` | `true`: إذا لم يكن في الخبر صورة، تؤخذ صورة المقال من صفحته (og:image) |
| `page_summary` | `true`: إذا لم يكن في الخبر ملخص، يؤخذ وصف الصفحة |
| `show_authors` | `true`: إظهار أسماء المؤلفين |
| `icon` / `color` | أيقونة المصدر ولون البطاقة (مثل `"#ED4245"`) |

**إعدادات القناة:** `key` (اسم قصير بالإنجليزية)، و`name`، و`type` (`"forum"` أو `"text"`)،
و`webhook_secret` (اسم الـ Secret)، و`color`، و`limit`، و`applied_tags` (أرقام وسوم المنتدى، حتى 5).

- **عتبة Hacker News:** غيّر `points=300` في رابطه: رقم أكبر يعني أخبارًا أقل وأشهر.
- **قناة خامسة:** أضفها في `feeds.json` باسم Secret جديد، ثم أضف الـ Secret في GitHub،
  وأضف سطرًا له تحت `env:` في `.github/workflows/notify.yml` مثل الأسطر الأربعة الموجودة.
- **المصدر الجديد** يسجّل في أول تشغيل ما فيه الآن دون نشره، ثم ينشر الجديد فقط.
- **نوع القناة يجب أن يطابق Discord:** `forum` لقناة المنتدى و`text` للقناة النصية (انظر «حل المشكلات»).

## كيف يمنع التكرار؟

- يحفظ في `state.json` لكل مصدر بصمات (hash) آخر 200 خبر رآها (من `guid` أو الرابط)، وتاريخ أحدث خبر.
- لا ينظر إلا في أحدث 50 خبرًا من كل مصدر (مصدر arXiv وحده فيه أكثر من ألف ورقة يوميًا).
- من الأخبار التي لم يرها، ينشر الأحدث حتى الحد (`limit`)، ويسجّل الباقي «مُتجاهَلًا» فلا يُنشر لاحقًا.
- يتجاهل أي خبر أقدم من أحدث خبر رآه في مصدره بأكثر من 7 أيام (يحمي من إعادة نشر الأرشيف إذا غيّر موقع روابطه).
- لا يُسجَّل الخبر «منشورًا» إلا بعد أن يقبله Discord؛ إذا فشل الإرسال يُعاد في التشغيل التالي.
- يُحفظ `state.json` بـ commit في مستودعك، ولا يتغيّر إلا عند وجود جديد.

## على جهازك (للتجربة فقط)

تحتاج Python 3 (موجود عندك: الأمر `py -3`). من داخل هذا المجلد:

```powershell
py -3 notifier.py --dry-run --latest 1
```

| الخيار | المعنى |
|---|---|
| `--dry-run` | اطبع الرسائل ولا ترسلها، ولا تغيّر `state.json` |
| `--latest N` | انشر أيضًا أحدث N أخبار من كل مصدر حتى لو نُشرت من قبل (للتجربة) |
| `--channel KEYS` | قنوات محددة فقط، مثل `research` أو `ai,security` |
| `--no-translate` | دون ترجمة (أو `TRANSLATE=0`) |
| `--config PATH` / `--state PATH` | مكان `feeds.json` و`state.json` |

اختبارات السكربت (دون إنترنت):

```powershell
py -3 -m unittest discover -s tests -v
```

النشر الفعلي يتم من GitHub Actions؛ لا تضع روابط الـ Webhooks في ملفات على جهازك.

## ملاحظات

- **التأخير:** GitHub لا يضمن دقة مواعيد التشغيل المجدول، وقد يتأخر بضع دقائق، وأحيانًا أكثر وقت الزحام.
- **عدد مرات التشغيل:** يحدده السطر `cron` في `.github/workflows/notify.yml`، وتوقيته بـ UTC.
  القيمة الحالية `"8 3,9,15,21 * * *"` تعني 4 مرات يوميًا.
- **التعطيل التلقائي:** يعطّل GitHub الـ workflows المجدولة في المستودعات العامة بعد 60 يومًا بلا نشاط.
  تحديث `state.json` بـ commit عند كل جديد يمنع ذلك. إن حدث، تعيد التفعيل من تبويب Actions.
- **@everyone:** الرسائل تُرسل مع `allowed_mentions` فارغة، فلا يستطيع أي عنوان أن ينادي أعضاء السيرفر.
- **جودة الترجمة:** ترجمة آلية، وقد تكون ركيكة أحيانًا؛ العنوان الإنجليزي الأصلي دائمًا في أسفل البطاقة.
  لتثبيت ترجمة مصطلح، أضفه إلى القائمة `GLOSSARY` في `notifier.py`.

## حل المشكلات

| المشكلة (في سجل التشغيل) | الحل |
|---|---|
| `DISCORD_WEBHOOK_... is not set ... channel ... skipped` | الـ Secret غير موجود أو اسمه مختلف. باقي القنوات تعمل، لكن التشغيل يظهر فاشلًا ❌ |
| `HTTP 400` مع الرمز `220001` | القناة منتدى في Discord لكنها `"text"` في `feeds.json`: غيّرها إلى `"forum"` |
| `HTTP 400` مع الرمز `220003` | القناة نصية في Discord لكنها `"forum"` في `feeds.json`: غيّرها إلى `"text"` |
| `HTTP 400` مع الرمز `40067` | المنتدى يشترط وسمًا لكل منشور: أوقف خيار الوسوم الإلزامية أو أضف `applied_tags` |
| `HTTP 401` أو `404` (`10015`) | الـ Webhook حُذف أو الرابط ناقص: أنشئ واحدًا جديدًا وحدّث الـ Secret |
| تحذير ⚠️ باسم مصدر (مثل `HTTP 403` أو `not a valid RSS/Atom feed`) | الموقع متوقف مؤقتًا أو غيّر رابطه. باقي المصادر تعمل. إذا استمر أيامًا فاستبدل الرابط أو احذفه |
| البطاقات بالإنجليزية وفي السجل `Translation is off for the rest of this run` | نفدت حصة MyMemory: أضف `MYMEMORY_EMAIL` (الخطوة 5) |
| فشل خطوة `Save state.json` بخطأ `403` | **Settings ← Actions ← General ← Workflow permissions** ← اختر **Read and write permissions** |
| لا يظهر شيء بعد أول تشغيل | طبيعي: أول تشغيل يسجّل الموجود فقط. جرّب `latest` = `1` كما في الخطوة 6 |
